这是一个微信小程序的实现，包含了一些汇报用的文档，可以作为作品的参考。后面可以基于这个进行改动形成我们自己的作品。

后续如果选择基于此小程序进行我们的作品开发，参与开发和测试体验的同学需要提供一下微信号，以便管理员将你们加入到开发者名单里，这样就自动有了小程序的体验权限，并可以自己更新当前体验版本。
